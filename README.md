# Employee Salary Manager

Projeto desenvolvido em C# para praticar Programação Orientada a Objetos.

## Objetivo

Cadastrar funcionários, impedir IDs duplicados, aplicar aumento salarial e listar os funcionários atualizados.

## Tecnologias

- C#
- .NET
- Visual Studio 2022

## Conceitos aplicados

- Programação Orientada a Objetos
- Classes
- Objetos
- Encapsulamento
- Construtores
- Métodos
- List<T>
- Validação de dados
- Sobrescrita de ToString()

## Exemplo de saída

```text
List of employees:

1, Maria, 2500.00

2, João, 3200.00

3, Pedro, 4100.00
```
